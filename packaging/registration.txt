# ShellDrive registration data: the single source for the per-user setup (apps/shelldrive-setup) and
# for the MSI registry tables that tools/sd-regtable will generate (04 §6.6, D45).
#
# One row per registry value:   subkey|value name|type|data|feature
#   subkey      relative to the hive chosen by the install mode (HKCU per-user; HKLM per-machine, MSI).
#               Empty subkey is not allowed. Backslashes are literal.
#   value name  empty = the key's default value.
#   type        SZ | DWORD (DWORD data is a decimal number or a placeholder that expands to one).
#   data        literal text, with placeholders expanded by the installer:
#                 [INSTALLDIR]  install folder, with a trailing backslash
#                 [VERSION]     product version (VERSION file)
#                 [FLAVOUR]     flavour name of the installed payload (x86-ia32, x64-modern, ...)
#                 [SIZEKB]      installed size in KB (rounded up)
#   feature     core (always written) | autostart (written only when sign-in start is chosen)
#               | shellext (the shell extension's rows: the MSI puts them in the ShellExt feature, the per-user setup
#                 writes them with the other rows; they match apps/shelldrive-shellext/shellext_register.c, 03 §8.5)
#               | shellext32 (the 32-bit view of the shell extension, 04 §8.3, 03 §8.5: the same CLSIDs and handlers
#                 with the x86 DLL in Program Files (x86), written by the MSI of the x64 flavours only as Win64="no"
#                 components. The per-user setup has no x86 DLL and skips these rows. Approved stays shared: it is
#                 not under Software\Classes, so it is not redirected and its one row (shellext) serves both views.)
#   [INSTALLDIR32]  the 32-bit install folder of the x64 MSI (Program Files (x86)\LibreStatic\ShellDrive\, with a
#                 trailing backslash); shellext32 rows only
# Rows are written and removed in file order. Keys are removed by the uninstaller when empty.
# Lines starting with # are comments. A "|" never appears inside data.
