# Test vector provenance (sd_crypto)

Everything under `tests/vectors/` is test **data**, never code (decisions.md D1, 01 §2.5). It is read
at run time by `sd-test-crypto` (`tests/unit/sd_crypto`).

## `wycheproof/`

- Source: Project Wycheproof, https://github.com/C2SP/wycheproof, directory `testvectors_v1/`,
  commit `d17cc89fa5c8f4f4d378b5385ebf75da5d0926c9` (HEAD on 2026-10-24). License: Apache-2.0.
- Files taken (SHA-256 of the downloaded JSON):
  - `aes_gcm_test.json` `985e5ecc172e181eaf49e89508b9470dcf478002eb7e8559c707eb42dc97dfe7`
  - `chacha20_poly1305_test.json` `fe61d25f90e1bde4461d00eafe61049e5f29bd999f36b766df9cda90906ad53d`
  - `ed25519_test.json` `ea80ffebac085e21cb9d3e903e7fa2b448d96702da5b31f061d0b83b430b74b3`
  - `x25519_test.json` `35c3f5231cf25cc640b524d403461deee9e49441d5d915a3a25b2c8ff5adbe7d`
  - `hmac_sha256_test.json` `2d201cfa61d1bf95e6f5d07d96634b4a348b31e8eaa277ad7c8d09677b7a743f`
  - `hmac_sha512_test.json` `b6c90477bdb4a6fc8ee3d1f7b2c0b69a8dfffab34718abaa6cabd71cc2ba1207`
- Converted to the compact line format described in `wycheproof/convert.py` (our script):
  `python -I tests/vectors/wycheproof/convert.py <download dir> tests/vectors/wycheproof`.
  Only AEAD groups with a 96-bit IV and a 128-bit tag are kept (the sd_crypto API takes exactly
  those); the header line of each `.txt` records how many tests were skipped for that reason.

## `openssh/`

- `ed25519_aes256ctr_r16.key` (+ `.pub`): generated on 2026-10-24 with
  `ssh-keygen -t ed25519 -a 16 -N "correct horse battery staple" -C "sd_crypto test fixture"`
  (OpenSSH_for_Windows_9.5p2). Used as an end-to-end vector for bcrypt_pbkdf + aes256-ctr + Ed25519
  key derivation. The passphrase is part of the fixture, not a secret.

## `refimpl/`

- `x25519_random.txt`: 500 random X25519 cases (including non-canonical u >= p and inputs with
  bit 255 set) produced by `refimpl/x25519_ref.py`, our own deliberately simple big-integer
  implementation of RFC 7748 §5 (independent arithmetic cross-check, 01 §2.7.4). Regenerate with
  `python -I tests/vectors/refimpl/x25519_ref.py tests/vectors/refimpl/x25519_random.txt`.

## Vectors embedded in the test sources

- FIPS 180-4 / NIST CSRC examples (SHA-256/384/512), RFC 4231 (HMAC-SHA-256/384/512), RFC 7914 §11
  (PBKDF2-HMAC-SHA-256), FIPS 197 Appendix C (AES), NIST SP 800-38A F.2/F.5 (CBC, CTR), the GCM
  specification test cases (McGrew-Viega, used by SP 800-38D validation), RFC 7748 §5.2 and §6.1
  (X25519), RFC 8032 §7.1 (Ed25519), RFC 8439 §2.3.2, §2.5.2 (ChaCha20 block, Poly1305).
- bcrypt_pbkdf: the three vectors published with Go's
  `golang.org/x/crypto/ssh/internal/bcrypt_pbkdf` tests, stated there to be generated by the OpenBSD
  reference implementation (numbers only; no code taken).
